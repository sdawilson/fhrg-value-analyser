# Value Analyser

The web edition of the Value Analyser II Excel workbook: a balanced-scorecard toolkit for value for money, best practice and strategic options, for member authorities of the Future Highways Research Group. It runs at https://value-analyser.fhrg.co.uk.

- `src/`: the server, in TypeScript, for a bunny.net Magic Container.
- `public/index.html`: the page. Opened on its own, it runs on fictional sample data.
- `test/`: `npm test` runs everything against a simulator, with no accounts or keys.
- `SETUP.md`: how it's set up. `CLAUDE.md`: how it's built, and the rules that must hold.
